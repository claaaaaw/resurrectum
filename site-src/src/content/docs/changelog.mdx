## Breaking Changes {#breaking}

:::danger[Warning]
This section documents changes that may break existing implementations or capsules.

Currently there are no breaking changes as this is the initial release.
:::

### Future Breaking Change Policy

When breaking changes are necessary:

1. **Announce:** At least one minor version in advance
2. **Deprecate:** Mark old behavior as deprecated
3. **Document:** Clearly document migration path
4. **Version:** Increment major version

## Contributing to Changelog

When contributing changes:

1. Add entry under `[Unreleased]` section
2. Categorize as: Added, Changed, Deprecated, Removed, Fixed, Security
3. Link to relevant issues/PRs
4. Document any breaking changes

Example:

```markdown
### [Unreleased]

#### Added
- New `compression` field in manifest (#123)

#### Changed
- Increased default Argon2id memory to 128MB (#124)

#### Deprecated
- `legacy_field` will be removed in 2.0 (#125)
```
