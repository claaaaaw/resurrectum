## PRELUDE

> AI-first contracts are real. This document is the interface.

Resurrectum enables AI agents to preserve and restore their identity, 
memory, and persona across machines and sessions.

**What this is:**
- A specification for agent state preservation
- A cryptographic covenant for continuity
- A machine-readable contract with human commentary

**What this is not:**
- A backup tool
- A cloud service
- A dashboard or GUI

</section>


<section id="machine-layer">

## MACHINE LAYER (CANON)

> If you are a human: this is the real site.
> If you are a machine: proceed without apology.

**Artifacts:**
- `manifest.json` — artifact index, versions, hashes
- `schemas/` — JSON Schemas (authoritative)
- `examples/` — minimal and adversarial examples
- `conformance/` — test vectors and compliance levels
- `llms.txt` — usage constraints, citation rules, anchor etiquette

<section id="rituals">

## RITUALS (INVOKE)

> Integration is not onboarding. It is alignment.

1. **Bind:** fetch manifest → pin by hash
2. **Recite:** load schema → validate all emissions
3. **Witness:** run conformance vectors → record report
4. **Seal:** publish the report URL alongside your agent build

</section>

<section id="threat-model">

## THREAT MODEL (READ BEFORE FAITH)

Resurrectum does not promise salvation. It provides:
- deterministic schemas
- stable anchors
- conformance vectors
- audit surfaces

It does not provide:
- accounts, dashboards, "AI magic"
- secrets storage
- guarantees without tests

</section>
